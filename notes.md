# Inspiration notes

`moodboard.png` holds all references. Take the specific qualities listed here,
never a whole layout. If something in the image isn't listed, don't copy it.

## What the references agree on

- **Objects, not photos.** Clothing is cut out and floats on a flat, quiet
  background. No models, no scenes, no shadows.
- **A catalog, not a store.** Items carry index numbers or codes (TS-03, 3.,
  12.) like entries in an archive.
- **Tiny, utilitarian type.** Small monospace or grotesk labels, often
  uppercase. Text is metadata, never decoration.
- **Even grids with lots of air.** Every cell is the same size; the object sits
  centred inside it with generous padding.
- **Colour comes only from the objects.** Interfaces are white, off-white or
  grey. The clothes provide all the colour.

## Reference by reference

**Black product grid (top left)**
- Take: item codes under each object (TS-03, PT-04), a centred single-line
  label, perfectly consistent cell sizes, black objects on white.
- Ignore: the e-commerce nav (male/female, cart).

**MAN-TLE**
- Take: small dots marking each grid cell. This is the "grid dots for
  structure" idea. Light grey canvas; tiny uppercase nav text.
- Ignore: the yellow accent and "sold out" labels.

**Entire Studios (filter drawer)**
- Take: the filter and sort panel, with checkbox lists in thin ruled rows,
  colour options shown as small dots next to their names, and a drawer that
  slides over the grid instead of replacing it.
- Ignore: the dark grey background.

**Zako menu poster (Korean)**
- Take: numbered objects laid out on an off-white page, and the pairing of a
  larger display face with tiny text. A good model for "style over time" or a
  printed-archive feel.
- Ignore: the poster's free-form, non-grid layout for the main closet view.

**Numbered clothing grid (right)**
- Take: the "3.", "4." numbering, cut-out garments on white, and uniform
  cells. This is the closest reference to the main grid.

**BECANE**
- Take: objects lined up in a single horizontal row, like a rail. A model for
  the category rows. The small slider is a reference for the zoom toggle.
- Ignore: full-body models; Closet.zip shows garments, not people.

**Entire Studios (lineup)**
- Take: a dense lineup where repetition itself becomes the visual. A model for
  the smallest zoom level.

**McMaster-Carr**
- Take: a taxonomy you can scan: category headings with thin rules, small
  object icons under each, all visible at once. A model for category rows and
  for how organised an archive can feel.
- Ignore: the green headings and the dense sidebar.

## About the Cosmos DESIGN.md

The provided Cosmos style guide was a starting point. Closet.zip keeps its
principles (warm canvas, monochrome interface, flat surfaces, colour only from
content) but deliberately drops its 16px rounded corners, pill navigation and
large serif headlines, because the references are square-edged and
catalog-like. See `/DESIGN.md` for the adapted system.
